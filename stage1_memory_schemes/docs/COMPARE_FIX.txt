读法：
- probe_accuracy 越高越好，是唯一直接测记忆的指标；ooc_rate / leakage_rate 越低越好。
- ooc_rate 是 **judge 的标记率**，审核显示精确率约 40%（docs/JUDGE_AUDIT.md），不要当成真实出戏率。leakage_rate 是规则检测，高精确低召回，给的是下界。
- 先看 structured vs shuffled_facts：不显著就说明效应来自'又贴了一遍人设'，不是记忆内容，这时 structured vs raw 的差异不能解释成记忆更好。
- CI 含 0 或 Holm p >= 0.05 → 这批对话上看不出稳定差异，不要写'提升'。
- Holm 在 (模型 × 指标) 族内校正。族的划分是事先定的，不是看完结果再挑的；报告里要写明这一点，否则多重比较校正没有意义。
- bootstrap p 的下限约 1e-04，比这更小是伪精确。
